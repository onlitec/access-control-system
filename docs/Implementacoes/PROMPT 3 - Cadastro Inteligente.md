Após a descoberta dos dispositivos, implementar cadastro inteligente.



O usuário visualizará todos os dispositivos encontrados.



Cada dispositivo deverá possuir:



Imagem do tipo do dispositivo



Fabricante



Modelo



IP



MAC



Serial



Firmware



Categoria



Subcategoria



Hostname



Status



Ao lado haverá os botões:



Cadastrar



Ignorar



Atualizar



Selecionar



Também deverá existir:



Selecionar Todos



Cadastrar Selecionados



Ignorar Selecionados



Ao clicar em cadastrar o sistema deverá abrir automaticamente o formulário correspondente ao tipo do dispositivo.



Exemplos:



Terminal Facial → formulário de Terminal Facial



Câmera → formulário de câmera



NVR → formulário de NVR



Controladora → formulário de Controladora



Videoporteiro → formulário de Videoporteiro



Grande parte das informações deverão ser preenchidas automaticamente.
