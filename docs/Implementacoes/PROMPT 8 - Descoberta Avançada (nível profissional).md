Transforme o módulo de descoberta em uma solução de gerenciamento de infraestrutura semelhante ao UniFi Controller, TP-Link Omada Controller, HikCentral Professional e HiTools Delivery.



Além da descoberta automática, implementar:



• Mapa da rede

• Topologia dos dispositivos

• Relação entre switches e equipamentos

• Descoberta via LLDP

• Descoberta via CDP

• Descoberta via SNMP

• Inventário automático

• Detecção de portas PoE

• Consumo PoE

• Velocidade das interfaces

• Temperatura dos dispositivos (quando suportado)

• Uso de CPU

• Uso de memória

• Espaço em disco

• Estado dos discos de NVR/DVR

• Licenças instaladas

• Certificados HTTPS

• Sincronização NTP

• Backup automático das configurações

• Comparação de configurações

• Atualização de firmware em lote

• Reinicialização em lote

• Teste de conectividade

• Teste de largura de banda

• Histórico completo de eventos



Toda a arquitetura deve ser modular para que novos fabricantes e protocolos possam ser adicionados apenas criando novos plugins, sem modificar o restante do sistema.



A interface deve permitir descoberta, inventário, monitoramento, cadastro, configuração e manutenção de dispositivos a partir de um único painel central.
